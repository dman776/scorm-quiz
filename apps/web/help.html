Overview

SCORM Quiz Builder lets you author graded tests and quizzes visually, then export a self-contained SCORM 2004 4th Edition package you can upload to Workday Learning or any conformant LMS. You can build questions by hand or import a whole quiz from Excel.

What the exported package does in your LMS:
  • Launches in the browser and talks to the LMS through the SCORM runtime.
  • Reports completion separately from pass/fail, plus raw, min, max, and scaled scores.
  • Reports per-question interaction data for detailed reporting.
  • Saves progress so a learner can leave and resume.
  • Enforces your passing score and attempt rules, and works offline (no external content).

The screen layout

The builder has four regions:

RegionWhat it holds
Top barSave status and the main actions: New Quiz, Validate, Preview, Export SCORM.
Left panelThe question list, the "Add question" control, Assessment settings, and the Excel / Project import & export buttons.
Center panelThe editor for the selected question (or the Assessment settings form).
Right panelThe live Validation list of errors and warnings.
Your work saves automatically to your browser. The Saved indicator in the top bar turns to Saving... briefly whenever you make a change.

Quick start

  1. Click Assessment settings and set the title and passing score.
  2. Pick a type from the dropdown and click Add, or use Import Excel.
  3. Fill in the prompt, answers, correct choice(s), points, and feedback.
  4. Click Validate and clear any errors on the right.
  5. Click Preview to take the quiz as a learner would.
  6. Click Export SCORM and upload the ZIP to your LMS.

Top menu: New Quiz

New Quiz clears the editor and starts a fresh, empty quiz. If the current quiz has questions, you are asked to confirm first so you do not lose work by accident.

"New Quiz" replaces what is on screen. If you might need the current quiz later, use Export project first (see Project JSON).

Top menu: Validate

Validate re-checks the whole quiz and refreshes the Validation panel on the right. Validation also runs continuously as you type, so this button is mainly a manual refresh.

Top menu: Preview

Preview opens the quiz in a pop-up exactly as a learner will see it: real navigation, scoring, feedback, the review screen, and a pass/fail result. Preview runs in standalone mode, so nothing is recorded to an LMS. Close the pop-up to return to editing.

Preview uses the same engine that runs inside the exported package, so what you see is what the learner gets.

Top menu: Export SCORM

Export SCORM builds and downloads a .zip that you upload to your LMS. If the quiz has validation errors, the export is blocked and the errors are shown on the right so you can fix them first. The ZIP contains everything needed to run offline, with imsmanifest.xml at the root.

Export needs the local API server running (npm run server, port 4000). If it is not running you will see a reminder.

Adding questions

In the left panel, choose a type from the dropdown and click Add. The new question appears in the list and opens in the editor with sensible starter content you can replace.

Building a hotspot question

  1. Add a Hotspot question, then Upload image. Keep it under 5MB — the image is embedded in the SCORM package so it works with no internet connection.
  2. Fill in Image alt text describing the picture for screen reader users.
  3. Drag a box on the image for each clickable region.
  4. Mark which region(s) are Correct, and give each a label. Labels are for you and the answer key — learners never see them, so a label can safely name the answer.
  5. Tick Allow the learner to select more than one region if several must be found. You then get the usual all-or-nothing, partial credit and weighted scoring choices.

Regions are stored as fractions of the image, so they stay put when the image scales on smaller screens. Hotspot questions cannot be created from Excel, because a spreadsheet cannot carry the image.

The question editor

Selecting a question in the list opens it in the center panel. Common fields for every type:

  • Prompt - the question text the learner reads.
  • Points - how much the question is worth.
  • Learning objective - optional tag used in reports.
  • Correct / Incorrect feedback and Rationale - shown in review.

The middle of the editor changes to match the type: an options list for choice questions, prompt/match rows for matching, an ordered list for sequence, exact value and tolerance for numeric, and accepted answers for short answer.

Scoring & answer options

For choice questions each row has three parts:

  • A radio/checkbox on the left to mark the option correct.
  • The answer or distractor text box (this is the wide field you type the answer into).
  • An optional compact score box for per-answer points (may be negative for a misconception).

Multiple select questions offer a Scoring strategy:

StrategyBehavior
All or nothingFull points only when the selection is exactly correct.
Partial creditProportional credit; wrong picks can deduct, floored at zero.
WeightedAdds up the per-answer score values you enter.
Use Add option to add choices and the small × to remove one.

Feedback & rationale

Provide Correct feedback, Incorrect feedback, and a Rationale. Whether learners see these, and when, is controlled in Assessment settings under Results display (for example, only after the final attempt).

Reorder, duplicate, delete

  • Reorder: use the up/down arrows on each list item.
  • Duplicate: in the editor header, copies the question as a new one.
  • Delete: in the editor header, removes it (with a confirm).

Validation panel

The right panel lists issues as you work:

  • Errors (red) must be fixed before you can export. Examples: missing title, no questions, a choice question with no correct answer, a numeric question with no value.
  • Warnings (amber) are advisory, such as a missing rationale or learning objective. You can export with warnings.

Import from Excel

You can author an entire quiz in Excel and load it in one click.

  1. Click Download template in the Excel area of the left panel.
  2. Fill in the Settings and Questions sheets (the template ships with a working example for every question type).
  3. Click Import Excel and choose your file.
  4. The quiz loads into the editor and a summary tells you how many questions imported and any issues.
Excel import uses the same API server as export. Start it with npm run server if you have not already.

Project JSON (save & reopen)

Use Export project to save the full editable quiz as a .json file, and Import project to load one back. This is the best way to keep a backup or move a quiz between machines. (Project JSON keeps everything; the SCORM ZIP is the finished package for the LMS.)

Accessibility

Both the builder and the exported quiz target WCAG 2.2 AA:

  • Everything is keyboard operable; press Tab to move and Space/Enter to select.
  • Choices use real radio/checkbox controls (even the "pill" style), so screen readers announce them correctly.
  • Sequence questions offer Move Up/Down buttons as a keyboard alternative to dragging.
  • Focus is always visible, and results and errors are announced to assistive technology.

SCORM & your LMS

The export is SCORM 2004 4th Edition, chosen because it reports CMI interaction data (the format your LMS guidance recommends). Because LMSs differ, verify these in your target LMS after uploading:

  • Completion and pass/fail appear as expected.
  • The score matches your chosen retention (highest/latest/first).
  • Per-question interactions are captured.
  • Exit and resume restore the learner's progress.
